# Application charts

Installable Helm charts (`type: application`). See [SPECIFICATION.md](../SPECIFICATION.md).

- Flat charts: `charts/<chart-name>/`
- Grouped by system: `charts/<system>/<chart-name>/`
- Retired charts: `charts/archived/` or `charts/<system>/archived/`

New charts belong here. Existing charts remain under `helm/applications/` until migrated.
