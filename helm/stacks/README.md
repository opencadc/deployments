# Stack (umbrella) charts

Umbrella charts that compose subcharts under `helm/charts/`. See [SPECIFICATION.md](../SPECIFICATION.md) and [ADR 0002](../../docs/adr/0002-umbrella-charts-for-related-systems-only.md).

The SC2 sandbox stack remains at `helm/applications/sandbox/stack/` until migrated to `stacks/sandbox/stack/`.
